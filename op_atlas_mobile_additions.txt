Cards become full-width
Touch-friendly buttons
Sticky filter button
No horizontal scrolling

Add Mobile Filter Drawer

Add this button immediately below the header:

<button id="filterToggle">
    🔎 Filters
</button>


Then wrap all sidebar content like this:

<div class="sidebar" id="filtersPanel">

    <!-- all existing filter controls -->

</div>

Add Mobile Drawer CSS
#filterToggle{
    display:none;
}

@media (max-width:768px){

    #filterToggle{
        display:block;
        position:sticky;
        top:0;
        z-index:100;
        background:#0078d4;
        color:white;
        border:none;
        width:100%;
        padding:14px;
    }

    #filtersPanel{
        display:none;
    }

    #filtersPanel.open{
        display:block;
    }

}

Add Drawer JavaScript

Add before </script>:

const filterToggle =
document.getElementById("filterToggle");

const filtersPanel =
document.getElementById("filtersPanel");

filterToggle.addEventListener("click", () => {

    filtersPanel.classList.toggle("open");

});
